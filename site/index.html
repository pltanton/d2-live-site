d2-live
Features Install Star

D2 · state machines · any editor

Draw it.

A live preview for D2 diagrams that you can also edit. Whatever writes the .d2 file, the picture follows; press E and the picture writes back — by exactly the lines you changed.

Install GitHub

Viewer

  • Live — redraws whenever the file changes, whoever wrote it
  • One server — open a file or a whole directory; switch files in the tab
  • Layouts and sketch — ELK, dagre or tala and hand-drawn mode, switched in place
  • Pan and zoom — position kept across redraws; F fits to screen
  • Export — copy or download PNG and SVG
  • From your editor — opens with the file via d2-live --lsp

Edit mode E

  • Basic editing by clicking for diagrams of shapes and arrows — state machines, flowcharts: rename, label, class, shape, style, connect, add, reverse, delete, comments
  • Code panel — click a shape to see its code, a line to see its shape; type and the picture follows, ⌘S saves
  • Minimal diffs — only the lines you touched change
  • Undo, and a choice when someone else edits the file at the same time
  • Containers, chains and sequence diagrams preview live and edit as code

Install

Nix

nix profile install github:pltanton/d2-live

Update: nix profile upgrade d2-live
Remove: nix profile remove d2-live

NixOS · home-manager

inputs.d2-live.url = "github:pltanton/d2-live";

environment.systemPackages = [
  inputs.d2-live.packages.${pkgs.stdenv.hostPlatform.system}.default
];

Update with nix flake update d2-live.

Anywhere with Go 1.25+

go install github.com/pltanton/d2-live@latest

Update: the same command.
Remove: rm "$(go env GOPATH)/bin/d2-live"

Then

d2-live diagram.d2      # or a directory of them

A tab opens with the live preview; press E to edit. Rendering and PNG export happen inside d2-live; the d2 CLI is only needed for the tala layout engine and for PNGs of diagrams with markdown labels. Editor integration and the rest are in the README.

Agent plugin

A d2-live skill teaches a coding agent to work with the preview: register the diagrams it writes, hand you the link, check they compile, and re-read the file before editing — you may be changing it in the tab. The repository is a plugin marketplace; in Claude Code:

/plugin marketplace add pltanton/d2-live
/plugin install d2-live@d2-live

Update: /plugin marketplace update d2-live
Remove: /plugin uninstall d2-live@d2-live

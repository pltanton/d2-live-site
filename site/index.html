A live preview for D2 diagrams that you can also edit. Whatever writes the .d2 file, the picture follows; press E and the picture writes back — by exactly the lines you changed.

What edit mode handles

By clicking

Diagrams made of top-level shapes and arrows — state machines, flowcharts, simple architecture boxes:

  • select a shape or an arrow and jump to its code
  • rename, with every reference following
  • label (markdown stays markdown), class, shape, style
  • add shapes and arrows, reverse, delete
  • the # comment above a declaration
  • class definitions in classes:

In the code panel

Everything D2 can draw previews live, and anything can be edited as text, with the picture following as you type. Clicking does not change these yet:

  • shapes inside containers
  • chains like a -> b -> c
  • sequence diagrams, layers, imports, globs

Install

Nix

nix profile install github:pltanton/d2-live

Update: nix profile upgrade d2-live
Remove: nix profile remove d2-live

NixOS · home-manager

inputs.d2-live.url = "github:pltanton/d2-live";

environment.systemPackages = [
  inputs.d2-live.packages.${pkgs.stdenv.hostPlatform.system}.default
];

Update with nix flake update d2-live.

Anywhere with Go 1.25+

go install github.com/pltanton/d2-live@latest

Update: the same command.
Remove: rm "$(go env GOPATH)/bin/d2-live"

Then

d2-live diagram.d2      # or a directory of them

A tab opens with the live preview; press E to edit. The preview renders in-process — the d2 CLI is only needed for PNG export and the tala layout engine. Editor integration and the rest are in the README.

With Claude Code

The repository is also a Claude Code plugin marketplace with a d2-live skill. When Claude writes or edits a diagram, it registers the file with your running d2-live and hands you the preview link instead of restarting the server on every change, checks that the diagram compiles, and re-reads the file before each edit — you may be changing it in the tab at the same time.

/plugin marketplace add pltanton/d2-live
/plugin install d2-live@d2-live

Update: /plugin marketplace update d2-live
Remove: /plugin uninstall d2-live@d2-live

Or link the skill from a clone instead of installing the plugin:
ln -s "$PWD/skills/d2-live" ~/.claude/skills/d2-live

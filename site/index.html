    See it live

    The real thing, at real speed

    Something else writes the file, the tab follows; then a state is renamed from the inspector.

    Fast

    Layout and rendering run in-process with a warm ELK: a redraw of a 12-state machine takes about a quarter of a second, and panning moves a ready picture instead of repainting every label.

    One server, every diagram

    The first d2-live becomes the server, later calls add files to it. Point it at a directory and every *.d2 lands in the tab's file list.

    Opens from your editor

    Attach d2-live --lsp as a language server: opening a .d2 opens its preview, closing the editor stops the server.

    The file stays the truth

    Typing previews without saving until ⌘S. Edits from elsewhere stream in; if one races your unsaved typing, you choose whose wins.
